# Markdown 注释编辑器

在工作区注释框里直接写 Markdown，并随时切换到实时预览。脚本注释从此可以像文档一样排版——标题、列表、表格、代码块都能正常呈现，不必再挤成一段纯文本。

> 启用本插件将无法折叠注释。

## 使用方法

注释框顶栏右侧会出现一个切换按钮，点击即可在两种模式之间切换：

| 模式 | 按钮 | 说明 |
| --- | --- | --- |
| 编辑模式 | 编辑 | 常规文本框，输入 Markdown 源码 |
| 预览模式 | 预览 | 隐藏文本框，显示渲染后的结果 |

- 也可以按快捷键 **Ctrl+M** 切换。快捷键只在焦点位于该注释框内（或已经处于预览模式）时生效，不会干扰工作区的其它输入。
- 每次进入预览模式都会按当前内容重新渲染，改完再切过去就能看到最新结果。
- 预览区域可以独立滚动，长注释不会撑破注释框。

## 支持的语法

### 块级

| 语法 | 写法 |
| --- | --- |
| 标题 | `# 一级` 到 `###### 六级`，也支持在文本下方加 `===` 或 `---` |
| 分隔线 | `---`、`***` 或 `___` |
| 引用 | `> 文本`，支持 `>>` 嵌套与跨行续写 |
| 无序列表 | 以 `- `、`* ` 或 `+ ` 开头 |
| 有序列表 | 以 `1. ` 或 `1) ` 开头，起始编号任意 |
| 列表嵌套 | 每缩进 2 个空格深入一层 |
| 任务列表 | `- [ ]` 待办、`- [x]` 已完成（复选框为只读展示） |
| 代码块 | 用三个反引号或三个波浪线包裹，可标注语言 |
| 表格 | 表头 + 分隔行构成，用 `:---`、`:---:`、`---:` 控制左 / 中 / 右对齐 |
| 硬换行 | 行尾加两个空格或一个 `\` |

代码块示例：

````markdown
```js
const message = 'Hello world';
```
````

### 行内

| 语法 | 写法 |
| --- | --- |
| 粗体 | `**粗体**` 或 `__粗体__` |
| 斜体 | `*斜体*` 或 `_斜体_` |
| 粗斜体 | `***粗斜体***` |
| 删除线 | `~~删除线~~` |
| 高亮 | `==高亮==` |
| 行内代码 | `` `代码` `` |
| 链接 | `[文字](https://example.com)` |
| 自动链接 | `<https://example.com>` |
| 图片 | `![说明](https://example.com/a.png)` |
| 转义 | 在标点前加 `\`，例如 `\*星号\*` |

各种语法可以组合使用——引用里放列表、列表项里放代码块、表格单元格里用粗体和行内代码，都能正确渲染。

## 设置项

| 名称 | 默认值 | 说明 |
| --- | --- | --- |
| 默认模式 | `edit` | 注释打开时进入的模式 |
| 切换快捷键 | `Ctrl+M` | 在编辑与预览之间切换的快捷键 |
| 渲染原始 HTML | `false` | 是否放行注释中的原始 HTML |

### 默认模式

决定新建或加载注释时进入哪种模式。

**`edit`**（默认）：先进入编辑模式写内容，需要时再切到预览。

**`preview`**：直接以渲染结果打开，适合把注释当作项目说明文档来阅读。

### 切换快捷键

在编辑与预览之间切换的快捷键，例如 `Ctrl+M`、`Alt+M`、`Ctrl+Shift+M`。

- 必须包含至少一个修饰键（`Ctrl` / `Alt` / `Shift`）。若只填单个字母，会回退为默认的 `Ctrl+M`，以免吞掉正常输入。
- 快捷键只在焦点位于注释框内时生效。

### 渲染原始 HTML

**启用时**，注释里写的原始 HTML 会被直接渲染。仅建议在自己的、可信的项目中开启。

**禁用时**（默认），所有 HTML 都会被转义，`<script>` 之类的内容只会以纯文本显示。

## 安全性

- 注释内容默认**全部转义**，不会执行注释里写的任何 HTML 或脚本。
- 链接只放行 `http`、`https`、`mailto` 和页内锚点 `#`。
- 图片只放行 `http`、`https` 和 `data:image/`。
- `javascript:` 等危险协议会被拦截：链接回退为 `#`，图片则按纯文本显示。
